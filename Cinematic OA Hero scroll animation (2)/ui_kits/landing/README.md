# OAHelper landing — UI kit

Static, component-built recreation of the marketing landing page. The production-fidelity, scroll-animated source of truth is `OAHelper Landing.dc.html` at the project root (cinematic hero, sticker-to-terminal sync, card pile sort, See/Solve/Clear 3D tile, pixel-dissolve transitions).

Sections: `Hero.jsx`, `ValueSection.jsx`, `CompareSection.jsx`, `ProofSection.jsx` (stats, ticker, testimonials), `CloseSection.jsx` (closing panel + footer). `index.html` composes them and adds the interactive Question of the Day tab (hover or click to open; auto-peeks once).

The scroll choreography is not reproduced here — each section is shown in its settled end state.
