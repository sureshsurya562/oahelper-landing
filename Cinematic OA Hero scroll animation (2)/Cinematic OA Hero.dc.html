2. Balance the Warehouses

There are n warehouses in a row. Warehouse i holds stock[i] units. In one operation you can move a single unit to an adjacent warehouse.

Return the minimum number of operations needed so every warehouse holds the same number of units, or -1 if that is impossible.

Example 1
Input: stock = [1, 0, 5] Output: 4
Constraints
1 ≤ n ≤ 10⁵
0 ≤ stock[i] ≤ 10⁴
